# موقع Response Spectrum (نسخة ثابتة + لوحة تعديل)

موقع ثابت (HTML) بدون ووردبريس، بنفس التصميم والحركات، بلغتين:
الإنجليزي على `/` والعربي على `/ar/`.
التعديل على المحتوى من لوحة بالمتصفح على `/admin/` بدون كود.

## كيف يشتغل

1. المحتوى مخزّن كملفات JSON داخل مجلد `content/`.
2. لوحة التعديل (Sveltia CMS) بتعدّل هالملفات عبر GitHub.
3. كل حفظ بيعمل نشر جديد تلقائي على Netlify أو Cloudflare Pages (حوالي دقيقة).
4. الأمر `node build.mjs` بيحوّل المحتوى لصفحات في مجلد `dist/`. ما في أي مكتبات لازم تتركّب.

## 1) الرفع على GitHub

1. افتح حساب على github.com (مجاني) وأنشئ مستودع (Repository) جديد.
2. ارفع كل ملفات هالمجلد للمستودع (زر Add file > Upload files).

## 2) النشر

### الخيار أ: Netlify (الأسهل مع لوحة التعديل)

1. Add new site > Import an existing project، واختار المستودع.
2. الإعدادات بتنقرا تلقائياً من `netlify.toml` (الأمر `node build.mjs`، والمجلد `dist`). اضغط Deploy.
3. لتفعيل الدخول للوحة التعديل: من إعدادات الموقع على Netlify ادخل على قسم OAuth (غالباً تحت Access & security)، وركّب مزوّد GitHub واتبع الخطوات. أسماء القوائم عند Netlify ممكن تتغير، فاعتمد على الاسم OAuth.
4. افتح الملف `static/admin/config.yml` وغيّر السطر `repo:` إلى `اسم-حسابك/اسم-المستودع`.
5. ادخل على `https://موقعك/admin/` وسجّل دخول بحساب GitHub.

نموذج التواصل بيشتغل تلقائياً مع Netlify Forms، والرسائل بتوصلك من لوحة Netlify (قسم Forms).

### الخيار ب: Cloudflare Pages

1. Workers & Pages > Create > Pages > Connect to Git، واختار المستودع.
2. Build command: `node build.mjs` و Build output directory: `dist`.
3. لوحة التعديل على Cloudflare تحتاج خدمة دخول صغيرة (Worker). استخدم المشروع المفتوح `sveltia-cms-auth` واتبع شرحه: بتسجّل OAuth App على GitHub وبتضيف GITHUB_CLIENT_ID للـ Worker وغيرها حسب شرحه. بعدها فعّل السطر `base_url:` في `static/admin/config.yml` وحط فيه عنوان الـ Worker.
   (إذا كنت أنت لحالك اللي بتعدّل، لوحة Sveltia بتسمح بالدخول بـ Personal Access Token من GitHub بدون Worker.)
4. نموذج التواصل: Cloudflare ما عنده خدمة نماذج جاهزة. استخدم Web3Forms أو Formspree (مجانية): انسخ عنوان الإرسال إلى خانة "Contact form: external form address" في لوحة التعديل، ومفتاح Web3Forms إلى خانة access key.

## 3) التعديل اليومي

ادخل `/admin/`. فيه خمس قوائم:

- **Site content**: كل نصوص الصفحة الرئيسية وصفحة من نحن، وبيانات التواصل والواتساب والخريطة وروابط السوشيال. كل نص له خانتين: English وArabic.
- **Services**: الخدمات (لكل خدمة صفحة خاصة).
- **Projects**: المشاريع (صورة، نوع، موقع، سنة، نص).
- **Team**: الفريق.
- **Clients**: العملاء. ارفع الشعار PNG أو SVG بخلفية شفافة، وإذا ما رفعت شعار بيظهر الاسم نصاً.

ملاحظات:
- اسم الملف بيتولد من الحقل الإنجليزي (العنوان أو الاسم)، فاكتبه دائماً بالإنجليزي.
- الحقل Order بيحدد الترتيب (1 يظهر أولاً).
- الصور المرفوعة بتتخزن في `static/uploads`.
- إذا خليت خانة عربية فاضية، بيظهر النص الإنجليزي مكانها.

## 4) ملفات التصميم والحركات

- `src/style.css`: الألوان والخطوط (المتغيرات في أول الملف: `--brand` و`--gold` و`--graphite`).
- `src/main.js`: الحركات والطيف والمحاكي.
- `src/ar.json`: ترجمة النصوص الثابتة (القوائم والأزرار).
- الهيرو بيستخدم مكتبة p5.js، والمحاكي ثلاثي الأبعاد بيستخدم three.js (r128). بيتحملوا من cdnjs. لاستضافتهم عندك: حط الملفين `p5.min.js` و`three.min.js` داخل `static/vendor/` والموقع بيستخدمهم تلقائياً.

## 5) تجربة محلية (اختياري)

```
node build.mjs
npx serve dist
```

يلزم Node.js 18 أو أحدث.
